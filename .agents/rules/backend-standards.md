# Padrões Django e APIs

Use separação clara de responsabilidades, validação no servidor, controle de permissões por recurso e respostas de erro consistentes. Não exponha segredos nem detalhes internos em APIs. Evite lógica de negócio complexa nas views. Use testes para regras críticas.
